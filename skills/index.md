# Skills

This page describes the various skills available in the OpenClaw system.

## Home Automation Control

Control home automation devices through Home Assistant. This skill allows you to:

- Turn lights on/off
- Adjust thermostat settings
- Monitor security cameras
- Control smart plugs and switches
- Check sensor readings (temperature, humidity, etc.)

The integration connects to your Home Assistant instance to provide seamless control of your smart home devices.

## Todo List Management

Manage your personal todo list with comprehensive task management features:

- Add new tasks with priority levels and due dates
- Mark tasks as completed
- View pending and completed tasks
- Organize tasks by category
- Receive reminders for upcoming deadlines
- Track task statistics and progress

This skill provides an efficient way to keep track of your daily responsibilities and long-term goals.
